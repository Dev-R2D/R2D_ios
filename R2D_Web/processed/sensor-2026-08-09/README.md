# Sensor Logger 2026-08-09

Sensor Logger 앱으로 기록한 스마트폰 GPS/IMU 데이터의 R2D 노면 상태 분석 산출물입니다.

## Files

- `sensor-2026-08-09-summary.csv`: 4초 창, 2초 이동 기준의 구간별 점수와 필터링 결과
- `sensor-2026-08-09-route-scores.csv`: GPS 포인트별 가장 가까운 구간 점수
- `sensor-2026-08-09-route.geojson`: 지도 표시용 주행 경로
- `sensor-2026-08-09-events.csv`: 영상 확인 후보로 쓸 상대적 고진동 스팟 10개

## Scoring

센서 데이터를 4초 단위로 나누고 2초씩 이동하면서 분석합니다. 각 구간에서 가속도 RMS, 최대 가속도, 자이로 RMS, GPS 속도와 위치 정확도를 계산합니다.

속도 차이로 인한 진동 변화를 줄이기 위해 아래 보정값을 사용합니다.

```text
속도 보정 진동값 = 가속도 RMS * (주행 중앙속도 / 해당 구간 속도)^0.8
노면 점수 = 96 - 56 * 해당 주행 내 진동 백분위 순위
```

점수는 최소 40점, 최대 96점으로 제한합니다. 전체 주행 점수는 점수가 적용된 4초 구간 점수들의 중앙값입니다.

## Exclusion

아래 조건 중 하나라도 해당하면 점수 산정에서 제외합니다.

- 속도 1.5m/s 미만
- 자이로 RMS 1.0 이상
- GPS 수평 오차 30m 초과
- 4초 구간의 가속도 또는 자이로 표본 250개 미만

## Map Legend

- 파랑: 잠원 실측 경로
- 노랑: 동탄 1차 실측 경로
- 보라: 동탄 2차 실측 경로
- 빨간 원형 스팟: 영상에서도 확인된 이벤트 후보
- 노란 원형 스팟: 센서에서만 검출된 이벤트 후보

빨간색은 파손 확정이 아니라 영상 검토 또는 현장 점검이 필요한 상대적 고진동 후보 구간입니다. 본 점수는 공인 IRI, PCI 또는 정밀 노면 측량값을 대체하지 않습니다.
